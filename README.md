# EXPIREDNOT — Pharmacy Inventory Intelligence

**EXPIREDNOT** is a modern pharmacy inventory and medicine expiry management platform designed to help retail, wholesale, and hospital pharmacies track stock, spot expiry risks early, and prevent inventory loss.

## ✨ Features

- **Art-Directed Namaste Welcome Screen**: Warm, cultural, minimalist entrance experience.
- **Split-Screen Authentication**: Sign in using either registered **Mobile Number (+91)** or **Email Address**.
- **Interactive Google Workspace SSO**: Authentic Google OAuth account selector dialog.
- **3-Step Pharmacy Onboarding Wizard**:
  - **Step 1: Pharmacy Details**: Chemist shop name, D.L. No. (protected), pharmacy type, contact number, optional address & GSTIN.
  - **Step 2: Owner / Responsible Person**: Name, role, +91 mobile number, and email.
  - **Step 3: Account Security**: Live password strength meter & 4-point requirements checklist.
  - **Step 4: Profile Review**: Structured summary cards with in-place edit actions.
  - **Step 5: Success State**: Verified badge & seamless transition to dashboard.
- **Expiry Risk Intelligence Widget**: Real-time batch watchlist preview with critical days remaining and monetary stock at risk.
- **Responsive Design**: Fully responsive across mobile (320px–430px), tablet, and desktop viewports.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure & accessibility labels.
- **CSS3**: Vanilla CSS with custom properties, 1px subtle gradient borders, and typography hierarchy (`Outfit`, `Plus Jakarta Sans`, `JetBrains Mono`).
- **JavaScript (ES6+)**: Pure vanilla state coordinator and validation logic.

## 🚀 Getting Started Locally

Serve the repository with any local static server:

```bash
# Python 3
python3 -m http.server 3000
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.
